# データ収集型とWeb検索型の比較

同じ候補都市・暮らしの条件・比較する視点で、二つの方式が回答します。比べるのは推薦先だけでなく、回答の前提をどこまで指定・確認できたかです。一方が常に正しい、常に優れるという判定はしません。

| 前提 | データ収集型（サブエージェントあり） | Web検索型（単独エージェント） |
|---|---|---|
| 地域 | 自治体コードでデータを対応付ける | 都市名と自治体コードを質問に含めて検索する |
| 集める情報 | 指標カタログと取得元を指定する | 同じ希望を手掛かりに検索結果から情報を選ぶ |
| 対象年・単位 | 指標ごとに記録し、比較可能性を検証する | ページごとの条件が揃うとは限らない |
| 回答へ渡す範囲 | 各担当には担当する指標のデータを渡す | 検索メモと参照先を同じ単独エージェントへ渡す |
| 欠損 | 未取得・地域の値なし・照合未確認を分ける | 検索で確認できなかった条件を回答に残す |
| 記録 | 指標、出典、対象年、データ取得・検証の記録 | 検索回数、検索語、短い要約、出典リンク |
| 再現性 | 同じ検証済みスナップショットを再利用できる | 同じ質問でも検索結果や回答が変わることがある |

## データ収集型

`DATA_MODE=open_data` は公式API・配布ファイルから事前同期したスナップショットを使います。各専門エージェントが担当軸のデータを読み、コマンダーが候補全体と暮らしの条件から回答します。評価中のライブAPI取得とは区別します。採点可能な指標が全部揃うとは限らず、未取得を推測で埋めません。

取得対象・地域・単位・対象年・欠損の扱いをアプリ側で指定し、回答に使ったデータを追跡できる構成です。来歴や形式の検証は、統計や回答の正しさ、物件単位の暮らしを保証するものではありません。

`DATA_MODE=government_api` は従来の契約APIアダプターです。指標・GISの変換には未実装の部分があり、APIキーを設定するだけで全指標が取得できる構成ではありません。標準の実データ運用は検証済みの `open_data` を使います。`DATA_MODE=mock` の値は画面確認用です。

## Web検索型

OpenAI Responses APIの `web_search` を使います。Copilotの挙動を再現する実装ではなく、一般的な短い検索・追加確認・回答の流れを比較用に実装しています。

`WEB_SEARCH_ROUNDS=3` が既定で、3または4を指定できます。候補都市すべてで回数を共有します。1ループの組み込みツール呼び出しは `max_tool_calls=1` で制限し、検索が1回完了したことを応答から確認します。その検索が複数の検索語を内部で実行することはあります。最後の回答生成では追加ツールを渡しません。回数を超えた応答や確認できない検索を成功として扱いません。

検索には前のループの短いメモを渡し、不足・矛盾・結論を変え得る条件を確認します。API方式の指標や所見は渡しません。検索から作った回答に数値のスコアを付けず、統一された統計の比較として扱いません。検索語・参照先はモデルと検索サービスが選ぶため、API方式と同程度の前提の固定はできません。

既定では既存の `OPENAI_MODEL` を使います。別の検索対応モデルを使う場合だけ `WEB_SEARCH_MODEL` を指定します。検索ツールの利用分はモデルの料金に加えて発生します。モデルが検索非対応、接続失敗、出典検証失敗の場合はエラーとして表示し、内在知識へ置き換えません。`LLM_MODE=mock` は検索0回・出典なし・推薦なしの「Web検索未実行」を返します。

## 商用利用と出典

検索エンジンのHTMLをスクレイピングせず、商用アプリに組み込める公式APIを使います。検索元を `e-stat.go.jp`、`stat.go.jp`、`mlit.go.jp`、`npa.go.jp` の一次情報に限定します。この制限も回答の前提として明示します。

OpenAIの出力に関する契約上の権利は、検索元の著作物を自由に転載できる権利ではありません。短い要約とクリックできる出典番号を表示し、第三者の本文・画像・地図の再配布は行いません。公式サイト上の第三者著作物にも個別の条件があるため、取得データの再配布は既存のライセンス・第三者権利検証を通したものだけに限定します。Web検索の回答はオープンデータとして配布しません。

- [OpenAI Web検索APIと引用表示](https://developers.openai.com/api/docs/guides/tools-web-search)
- [OpenAI Services Agreement](https://openai.com/policies/services-agreement/)
- [統計ダッシュボードの利用条件](https://dashboard.e-stat.go.jp/static/terms)
- [国土数値情報の利用規約](https://nlftp.mlit.go.jp/ksj/other/agreement.html)
- [警察庁の利用規約](https://www.npa.go.jp/rules/index.html)

旧 `knowledge_only` APIと既存の保存履歴は互換のため残します。旧モードはWeb検索を実行していないため、新しい比較結果と混同しないラベルを付けます。
