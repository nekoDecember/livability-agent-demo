# Livability データソースと指標の対応表

公開予定のため、評価軸・指標・取得元・欠損時の扱いをここにまとめます。Livability の点数は公式の住みやすさ評価ではなく、取得した指標を比較対象内で相対化した 0〜100 点の比較値です。

## 標準の全国自動同期（DATA_MODE=open_data）

標準設定は OPEN_DATA_SYNC_SCOPE=nationwide です。起動前に、登録不要と確認した公式公開経路から検証済みローカルスナップショットを作成し、評価リクエスト中はそのスナップショットを読み込みます。スクレイピング、ブラウザ自動操作、非公開エンドポイントは使いません。

| 評価軸 | 指標コード | 指標 | 取得元・経路 | 採点方向 |
|---|---|---|---|---|
| 移動・買い物 | retail_density | 小売・サービス事業所密度 | e-Stat 統計ダッシュボード API（全地域JSON取得） | 高いほど良い |
| 移動・買い物 | daytime_population_ratio | 昼夜間人口比率 | e-Stat 統計ダッシュボード API（全地域JSON取得） | 比較対象内で相対化 |
| 住まいコスト | housing_stock | 世帯あたり住宅ストック | e-Stat 統計ダッシュボード API（全地域JSON取得） | 高いほど良い |
| 住まいコスト | residential_land_price | 住宅地の地価調査基準地中央値 | 国土交通省 国土数値情報 L02（2026年全国GeoJSON ZIP） | 低いほど良い |
| 医療・子育て | clinics_per_100k | 人口10万人あたり診療所数 | e-Stat 統計ダッシュボード API（全地域JSON取得） | 高いほど良い |
| 医療・子育て | nursery_per_1000_children | 子ども千人あたり保育・幼児教育施設 | e-Stat 統計ダッシュボード API（全地域JSON取得） | 高いほど良い |
| 医療・子育て | schools_per_1000_children | 子ども千人あたり学校数 | e-Stat 統計ダッシュボード API（全地域JSON取得） | 高いほど良い |
| 医療・子育て | tertiary_education_campuses | 大学・短大・高専の掲載キャンパス数 | 国土数値情報 P29（2023年全国GeoJSON ZIP、市区町村コードで集計） | 高等教育を明示的に重視する場合だけ表示。常に採点対象外 |
| 安心・防災 | traffic_accidents | 人口10万人あたり交通事故件数 | 警察庁 交通事故統計情報の公式CSVを市区町村コードで集計。自治体コードと件数が照合できた場合だけ収録 | 少ないほど良い |
| まちの将来性 | population_retention_2040 | 2040年人口維持率 | e-Stat 統計ダッシュボード API（全地域JSON取得） | 高いほど良い |
| まちの将来性 | population_retention_2050 | 2050年人口維持率 | e-Stat 統計ダッシュボード API（全地域JSON取得） | 高いほど良い |

統計データと交通事故データは市区町村コードで対応付けます。交通事故CSVで自治体コードが見つからない場合は事故0件と解釈せず、行を作りません。事故件数を集計できた場合だけ人口で割って率に変換します。取得日、対象年、URL、元ファイルSHA-256、加工内容、利用条件はスナップショットのmanifestに記録します。

## 5軸の扱い

| 評価軸 | 比較する観点 | 標準同期での主な実測値 | 欠損時 |
|---|---|---|---|
| 移動・買い物 | 日常の買い物・都市活動へのアクセス | 小売密度、昼夜間人口比率 | 取得できた指標へ軸内ウェイトを再配分 |
| 住まいコスト | 住宅供給の余力 | 世帯あたり住宅ストック | 既存の検証済み行がなければ軸を除外 |
| 医療・子育て | 医療・保育・教育へのアクセス | 診療所、保育施設、学校の人口比。高等教育は条件に応じた参考情報 | 取得できた採点対象指標へ軸内ウェイトを再配分 |
| 安心・防災 | 交通安全・災害への備え | 交通事故率（自治体コードを照合できた地域のみ） | 取得・照合できなければ軸を除外。災害値を推測で補完しない |
| まちの将来性 | 将来人口の維持 | 2040年・2050年人口維持率 | 取得できた指標へ軸内ウェイトを再配分 |

画面でオフにした軸はAPIの enabled_axes から除外され、データ取得・専門Agent実行を行いません。利用者条件から作った重みは司令塔へ渡し、候補地の総合選択は各軸の点数を単純合算せず、司令塔が全専門Agentの所見と条件を合わせて判断します。

## カタログにあるが標準自動同期しない指標

以下はカタログに定義済みですが、標準の登録不要同期ではまだ自動取得していない指標です。`residential_land_price` は2026年版L02、`tertiary_education_campuses` は2023年版P29から同期するため、この表から除外しています。

| 軸 | 指標コード | 想定ソース | 標準同期しない理由 |
|---|---|---|---|
| 移動・買い物 | station_density, railway_lines, station_passengers | 国土交通省 不動産情報ライブラリ XKT015 | 標準の登録不要全国同期の対象外 |
| 住まいコスト | transaction_unit_price | 不動産情報ライブラリ XIT001 | APIキーが必要な経路を標準設定で使わない |
| 住まいコスト | official_land_price | 不動産情報ライブラリ XPT002 | APIキーが必要な経路を標準設定で使わない |
| 医療・子育て | emergency_hospitals | 不動産情報ライブラリ XKT010 | 標準同期の対象外 |
| 安心・防災 | crime_rate | e-Stat 社会・人口統計体系 K | 現在の市区町村別値を標準同期で確定していない |
| 安心・防災 | flood_exposure, landslide_exposure | 国土数値情報 XKT026 / XKT029 | 市区町村境界とのGIS集計値を標準同期で作成していない |
| 安心・防災 | shelters_per_10k | 国土数値情報 XGT001 | 標準同期の対象外 |
| まちの将来性 | working_age_retention, child_population_retention | 不動産情報ライブラリ XKT013 | 標準同期の対象外 |

未取得の指標は0点や推測値で埋めず、「未取得」として採点対象から外します。

## 登録・契約なしで拡張できる候補（2026-09-27確認）

現在は採点可能な22指標のうち9指標が高崎市・前橋市で使えます。さらに、条件に合う場合だけ見せる採点対象外の高等教育キャンパス情報を全国同期しています。これは取得先の上限ではありません。特に、統計ダッシュボードのメタデータから両市で比較可能な系列を追加選定することと、国土数値情報の公開ファイルを同期前にGIS集計することが次の候補です。

| 追加候補 | 対応する観点 | 公開データ | 利用条件と注意点 |
|---|---|---|---|
| 駅密度・路線・駅別乗降客数 | 移動 | 国土数値情報の鉄道2025年度版、駅別乗降客数2024年度版（乗降実績は2023年） | CC BY 4.0。駅データには自治体コードがなく市域への空間割当が必要。乗降数は事業者ごとに算出基準が異なり、非公表駅もある |
| バス停・バス路線 | 移動 | 国土数値情報のバス停留所2022年度版（全国GeoJSON ZIP 39.20MB） | CC BY 4.0。位置情報のみで自治体コードがなく、市域割当が必要。デマンドバス・高速バスを含まず、場所を特定できない停留所も一部欠落 |
| 住宅地の地価調査 | 住まいコスト | 国土数値情報L02（2026年、7月1日時点） | CC BY 4.0。コード000の住宅地基準地点を市区町村コードで集計。取引価格や家賃ではない。標準同期へ追加済み |
| 医療機関・学校の位置 | 医療・子育て | 国土数値情報の医療機関2020年度版、学校2023年度版 | 学校2023はCC BY 4.0かつ自治体コード付き。大学・短大・高専のキャンパス掲載数を条件付き参考情報として同期。P29の状態コード0（調査なし）は現況不明として注記し、定員・学部・通学時間は推定しない。小中高指標とは重ねて採点しない。医療機関2020は休止中・企業内施設を含み、自治体コードもなく、市域割当と鮮度確認が必要 |
| 洪水・土砂災害の曝露 | 安心・防災 | 国土数値情報の洪水浸水想定区域、土砂災害警戒区域 | CC BY 4.0のデータがあるが、一部制限がある項目は個別条件を継承する。市域面積比と居住人口比は別指標として扱う |
| 市区町村境界 | 上記の空間集計 | 国土数値情報の行政区域 N03（2026年1月時点） | CC BY 4.0だが、原典に測量法上の複製承認と二次利用時の申請可能性が明記されているため、この「申請不要」範囲では未使用。暫定境界もある |

統計ダッシュボードAPIは約6,000系列を持ち、利用登録不要ですが、系列によって市区町村データが存在しません。系列メタデータを検索し、「高崎市・前橋市の両方に値があり、単位・対象年・定義が比較可能」なものだけを採用します。カタログにある犯罪率、生産年齢人口、年少人口の保持率も、この条件を満たす系列が確認できた場合に追加します。

国土数値情報は同じサイト内でも条件がデータごとに異なります。たとえば避難施設は非商用扱いのため、この要件では取り込みません。「商用可」は出典・加工者を表示すれば商用利用・複製再配布が可能ですが、原権利者の条件やデータの不完全性も引き継ぎます。行政界が必要な空間集計は、CC BY表示だけで利用可と判断せず、原典の測量法・複製条件も確認します。項目単位でライセンスを確かめ、`open_data/manifest.json` に対象年、取得日、加工方法、原典、ライセンスを記録してから公開対象にします。

| 経路 | 商用利用 | 登録・契約 | 方針 |
|---|---|---|---|
| 統計ダッシュボードAPI | 可。出典と加工表示が必要 | API利用登録不要 | 標準同期の拡張候補。市区町村対応をメタデータで検査 |
| 国土数値情報のCC BY 4.0等の公開ファイル | 対象ファイルの条件内で可 | APIキー・個別申請なしでダウンロード可能 | 標準同期の拡張候補。データごとに条件を検査 |
| e-Stat API | 可 | ユーザー登録とアプリケーションIDが必要 | 登録不要を厳密に守る構成からは分離 |
| 不動産情報ライブラリAPI | API利用は無償。提供データの条件も確認 | API申請・審査・キー発行があり、承認時に利用契約が成立 | 取引価格などの拡張候補。ただし文字通りの「非契約」要件には含めない |
| OpenStreetMapデータ | 商用利用可。出典表示とODbLの継承条件あり | プロジェクトへの登録不要、ライセンス・利用条件への同意は必要 | 施設・道路の補助的な確認用。公共タイルサーバーを大量取得に使わず、データそのものを別途運用する |

2026年版L02全国GeoJSONを実際に集計し、住宅地コード・基準年・全国地方公共団体コードを照合した後に標準同期へ追加しました。2023年版P29は市区町村コード付きのため境界GISを使わず、学校コードとキャンパスコードの組で大学・短大・高専を重複排除して参考情報へ追加しました。未取得、未公表、値0は別の状態として保存します。他のGIS候補は、追加前に対象年・地域コードまたは空間集計・個別ライセンスを同じ手順で監査します。

## 高崎市・前橋市の確認済みカバレッジ

2026-09-27生成のスナップショットでは、高崎市（10202）・前橋市（10201）とも、採点可能な **22指標中9指標** を使えます。高等教育を明示的に重視する条件なら、採点対象外の参考情報として大学・短大・高専の掲載キャンパス数も表示します。P29 2023では両市とも9地点がありましたが、これらはすべて状態コード0（調査なし）のため現況確認済みの施設数ではありません。定員・学部・通学時間も分かりません。高崎市は住宅地の基準地点38件・中央値50,500円/㎡、前橋市は35件・51,100円/㎡でした。これは2026年7月1日時点の基準地点価格で、家賃や売買成約価格ではありません。警察庁CSVの事故レコードはこの2市の自治体コードに照合できず、安全軸の評価には使っていません。

| 軸 | 使用できる指標 | 状態 |
|---|---:|---|
| 移動・買い物 | 2/5 | 小売密度、昼夜間人口比。駅密度・路線・乗降客数は未取得 |
| 住まいコスト | 2/4 | 住宅ストックと住宅地の基準地点価格。家賃・取引価格は未取得 |
| 医療・子育て | 3/4 + 参考情報 | 診療所、保育、学校を採点。大学・短大・高専の掲載キャンパス数は条件付き表示。救急医療施設は未取得 |
| 安心・防災 | 0/5 | 軸全体を採点対象外。犯罪率・災害曝露・避難所は未取得 |
| まちの将来性 | 2/4 | 2040/2050年人口維持率。生産年齢・年少人口の推計は未取得 |

この2市での名寄せは成功しています。欠損は自治体名の照合ではなく、現在の全国同期で対象指標が取れていないことが原因です。住宅ストックを住居費と同一視したり、買い物・都市活動の統計を実通勤の利便性と同一視したりしないよう、画面では実際の指標数を併記します。
